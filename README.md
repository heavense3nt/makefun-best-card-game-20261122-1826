**Ember Clash** — an original tactical card battler. You are the Ember Knight, facing the Cinder Warden across the table. Both fighters start at 30 life; reduce the Warden to 0 to win. Each turn your energy grows (1, then 2, … up to 10) and you draw a card. Cards come in five elements, told apart by colour and glyph: ▲ Flame deals damage, ❄ Frost damages and shields, ❦ Verdant heals, ◆ Stone shields, ✦ Spark draws cards. Shield soaks damage first and then halves at the start of your turn; Burn ticks at the start of a turn. The Warden plays a readable heuristic — it heals when hurt, shields when threatened, and strikes when it can win — so its plays can be read and countered.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a card to play it (or press 1–7), Enter ends your turn, Esc returns to the title screen. All sound is synthesized live with the Web Audio API; nothing is fetched over the network.
